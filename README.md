## 这是什么

LSPosed / Xposed 模块：收到快递取件短信自动提取取件码 → 写入待办（ColorOS 16 写日历「待办」，小米写笔记「待办」）
→ 弹出通知（点击复制 / 一键已取件）。另含**桌面小组件**：

- **取件码桌面小组件**（液态玻璃风格）：📦 逐条展示、**上下滚动**浏览全部取件码；点击标题进入「取件码记录」
- **取件码记录页**：单条取走/删除 + **一键取走 / 一键删除**
- **设置**：写入目标（待办 / 仅组件 / 都写）、小组件字号（实时预览）、尺寸预设（2×2 / 4×2 / 5×3）
- 应用各页面 `excludeFromRecents`：按 Home 后自动从最近任务隐藏，不会被误划冻结

实测环境：一加 9 Pro · ColorOS 16 · Android 16 · KernelSU + LSPosed。需 **Root + LSPosed**。

> ColorOS 16 把"待办"从便签迁到了日历；官方任务接口需平台签名权限，第三方不可用 → 模块用 root + sqlite3 直写
> 日历待办库 `tasks.db`（与原版架构一致）。

## 使用前提与安装

1. 安装 APK（Release 页下载，核对 SHA-256）
2. LSPosed 启用模块；作用域勾选：**Android 系统(android) / 电话 / 短信 / com.android.providers.telephony**
3. **重启手机** → 打开一次 App → 允许通知与 KernelSU root
4. 桌面长按添加「取件码助手」小组件；字号/写入目标在 App「⚙️ 设置」调整

## 已知限制

- ColorOS 桌面**不支持滚动列表内的行点击/行按钮**（fillInIntent 被忽略）→ 取走/删除请在 App「📋 取件码记录」操作；
  组件滚动浏览、点标题进记录
- ColorOS 会把从最近任务划掉的应用"冻结"：本版页面已隐藏于最近任务（无卡可划），首次装/重启后打开一次 App 即可
- `tasks.db` 字段为逆向所得（含 `create_package` 设备哈希），ColorOS 大版本更新可能需复查

## 构建

JDK 17+：`./gradlew assembleRelease`（自行配置签名）。无 SDK 手工工具链复刻见 `build/build_termux.sh` 思路。
